# Audit register, revision 3.2

Baseline: commit `67e0ed2` (`main`, 25 October 2026). Audit and corrections made 26 October 2026 in response to the *Logos Atlas editorial, accuracy, learning and GitHub implementation brief, Rev1*.

**Scope.** All study-unit prose, the miracles, canon, comparison, Key Words, Trinity and tour narration data, the reader code and the build and check scripts were read. The map places, the people and movements units, the great stories, the deep-time data and the parallels table were not re-audited line by line; only the specific items below were checked in them. This is a substantial spot-check and correction pass, not a certification.

**How sources were checked.** The editing environment’s network policy blocked direct access to most sites (nature.com, PubMed, the British Museum, Wikipedia, Retraction Watch and others), so pages could not be opened. Claims were checked against web-search results that quote or summarise the sources. GitHub was reachable, so the text pipeline’s own source data (STEP Bible, scrollmapper, quran-api) was fetched and the generated texts were rebuilt and compared. Status values:

- **Verified (pipeline)**: checked mechanically against generated source text.
- **Verified (search)**: checked against search results quoting or summarising the source; page not opened.
- **From knowledge**: stated from knowledge of a standard work; not re-checked in this revision.
- **Open**: not resolved; listed under remaining issues.

Priority: **P1** scientific error, retraction, misleading sourcing; **P2** unsupported historical claim or interpretive overreach; **P3** labelling, interface and consistency.
